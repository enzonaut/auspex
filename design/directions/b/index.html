IName and moodDESIGNATIO

LEGIO OCVLVS

HANGAR DECK VII · ROMAN LEGION × MONO-EYE MOBILE SUIT · DIRECTION B

You sit in the cockpit of a legion war machine parked on hangar deck VII. Olive armor plate, stencilled unit numbers and hazard stripes frame every screen, and one red sensor eye sweeps while the system works. Rome gives the order of things: legion ranks, Latin labels, Roman-numeral workspaces and a bronze eagle as the unit insignia.

CVRSVS · SWEEPBoot, login, or 1+ fleet worker is working.
STATIO · HOLDAll idle, or screen locked. Eye rests at center and breathes.
SIGNVM · ALERTA worker waits for you. Eye flashes at center.

Signal rule: the mono-eye is the one status light of the whole OS. Boot, login, lock and the bar all use the same 3 eye states, so the operator reads machine and fleet state from 1 glance.

IXBuild notesADNOTATIONES

SDDM (login)

  • Buildable in QML. Chamfered plates are a Shape/ShapePath. The eye sweep is a SequentialAnimation on x. Fonts load with FontLoader from the theme folder.
  • Render the wallpaper to PNG first. QtSvg ignores blur, turbulence and other SVG filters. Ship a 5120×2160 PNG for the greeter background.
  • Qt version. The theme needs QtVersion=6 in metadata.desktop for a Qt 6 greeter. Test with sddm-greeter-qt6 --test-mode.
  • Session names come from .desktop files. The picker shows "Hyprland" and "Plasma (Wayland)". Map the 2nd name to "PLASMA" in QML.
  • The greeter does not retint on a theme switch (same as Omarchy). Colors are baked at install with sudo.

Plymouth (boot)

  • Use the script plugin. The eagle, visor slot, eye and 10 segments are sprites. The eye moves in the refresh callback (about 50 fps). The active segment pulses by opacity.
  • Text is the weak point. Image.Text needs the font inside the initramfs. Pre-render "SYSTEMA · INITIVM" and the numerals I to X as PNGs.
  • NVIDIA. Early KMS (nvidia-drm.modeset=1, modules in mkinitcpio) is required, or the splash starts late at low resolution. The foundation spec already adds the 4 modules.
  • Scale. Draw sprites for 5120 width. Plymouth does not scale per monitor DPI in a script theme.

Hyprland bar and session

  • Use Quickshell (QML), not waybar. GTK CSS has no clip-path, so chamfered plates and slanted workspace tabs need images in waybar. The eye sweep needs a real animation. Quickshell does both.
  • The fleet counter needs 1 data source. A command such as auspex-fleet-status --json polled every 2 s drives the counter and the eye state.
  • Window borders. Hyprland draws solid or gradient borders only. The active border is a 45° gradient accent → commander. HUD corner brackets on windows are not possible without a plugin. I left them off the desktop mockup.
  • Rounding 0, gaps 24 px. Angular plates need square corners. Ghostty and Claude Code take colors from the palette templates.

Lock (hyprlock) and general

  • Hyprlock has no free animation. The eye on the lock screen is a static image with the "hold" glow baked in. Clock, date and fleet line are label widgets.
  • Fleet on the lock screen needs a label with a cmd[update:2000] source. Keep it to counts only, no task text.
  • Latin labels always carry English ("SIGNVM · PASSWORD") so the login stays clear.
  • Contrast. accent #ff3b4e reaches 5.0:1 on background, but commander #a8202e fails for text. Use commander as fill only.
  • Originality. Eagle, visor, numbers and plates are drawn new. No real emblem, mobile-suit design or name is used.
