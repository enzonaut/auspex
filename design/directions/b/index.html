01Name and mood

Direction B · Empire Legion

Classis Aquilae

The Eagle's Bridge

You sit on the bridge of a legion flagship: black hull metal, steel instrument light, and one red status lamp that means someone needs you. Rome gives the order of things: cohorts number the workspaces, ranks name the user, and Latin labels every station. Gold is rare and earned, so it marks only the eagle, rank, and agents at work.

  • Hard angles chamfered corners, no rounding
  • Red lamp red means "needs you", nothing else
  • Cohorts Roman numerals for workspaces and agents
  • Scan lines on wallpaper and splash only, never on text

09Build notes

SDDM login

  • Chamfered corners. QML Rectangle only rounds. Chamfers need QtQuick.Shapes or a 9-slice PNG frame. Medium effort.
  • Wallpaper. Qt SVG supports only SVG Tiny 1.2: no blur filters. Ship a pre-rendered 5120x2160 PNG.
  • Fonts. The greeter runs as user sddm. Fonts must be system-wide in /usr/share/fonts, not in ~/.local.
  • Latin date. Roman numerals need a small JS function in QML. Easy.
  • Session names. Labels come from .desktop files, for example "Plasma (Wayland)". A name map in QML shows "PLASMA".
  • No retint. Omarchy does not retint the greeter on theme switch. A sudo step copies colors from colors.toml.

Plymouth boot splash

  • Images only. The script plugin draws PNG sprites. The eagle, wordmark, ring and scan lines are pre-rendered PNGs.
  • Progress. 10 chevron sprites, lit from the progress callback. The label "COHORS VI / X" is 10 pre-rendered PNGs, because text in initramfs needs fonts there.
  • 2 colors. omarchy-plymouth-set recolors assets to 1 text color with magick. Gold eagle plus red progress needs our own script.
  • Resolution. At 5120x2160 a 650 px eagle stays sharp only if the PNG is native size. Do not upscale.
  • Red arc. A rotating arc is cheap: 1 sprite with SetRotation.

Hyprland bar, windows, lock

  • Fleet counter. Needs a data source: poll horch ledger status every 5 s, or a socket. The red state must clear when no agent waits.
  • Bar chamfers. Easy in the Quickshell shell (QML Shapes). Waybar GTK CSS has no clip-path, so it falls back to square tabs.
  • Window corners. Hyprland draws only rounded or square borders. The mockup uses square corners on purpose: no chamfers on windows.
  • Workspaces I-X. A name map to Roman numerals. Easy.
  • Lock screen. hyprlock has labels, input field and blur. The fleet card is a label with cmd[update:5000]. Its chamfered frame is a PNG overlay.
  • Scan lines. Keep them baked into wallpaper and splash. A Hyprland screen shader puts them on text and costs GPU time.
