I

Name and mood

auspex · direction C · Galactic Empire Legion

CVNEVS

cuneus: the Roman wedge formation

A legion standard hangs in airless black sky: a gold eagle built from wedges above steel ships that fly in the old Roman cuneus. Every surface is cold durasteel, cut with inscribed capitals and one line of blood red that marks what is alive. The machine is the augur: it reads the flight of its agents as an auspex read birds, and the screen is its templum.

IX

Build notes

SDDM

  • The greeter is a QML theme. Load the fonts with FontLoader and keep the files inside the theme folder, readable by the sddm user.
  • The banner, wedge marker and segmented session picker are custom QML over sessionModel. The stock ComboBox does not give this look.
  • Blur is not used on login. If wanted later it needs MultiEffect or a pre-blurred image, so login uses login-bg.svg, the wallpaper without the fleet.
  • At 5120x2160 set a scale factor or the banner renders at about half size.
  • Omarchy does not retint the greeter from colors.toml. Its greeter background is fixed at #1a1b26, so this theme must ship its own SDDM theme.

Plymouth

  • Use the script plugin. Fonts in the initramfs are limited, so AVSPEX and any text must be pre-rendered PNGs.
  • The 10 wedges become 10 sprites with an opacity step per rank. Boot progress is not linear, so map it to ranks, not to time.
  • Gold gradients and the eagle must be pre-rendered. Plymouth cannot draw SVG.
  • Resolution varies between simpledrm and the real driver. Center from Window.GetWidth and test both.
  • The LUKS password prompt needs its own sprite set in the same style.
  • omarchy-plymouth-set uses magick to tint images. Ship ready PNGs so the theme does not depend on it.

Waybar

  • Waybar styles with GTK3 CSS. There is no clip-path, so the active workspace wedge must be a background-image or a bottom border.
  • Roman numerals come from format-icons on hyprland/workspaces.
  • The fleet counter is a custom module that runs a script. The source of herdr worker state is not verified yet (see commit 6ea62ec).
  • The ▲ and △ glyphs exist in Adwaita Mono. Keep the module in that font.
  • Check letter-spacing support before using tracked capitals in the bar.

hyprlock

  • hyprlock supports image, label, input-field and background blur, so this screen maps closely.
  • The fleet line is a label with cmd[update:5000] that calls the same script as the Waybar module.
  • The input-field draws a box by default. Set its outline and inner color to match the single underline.

What will be hard when this direction becomes SDDM, plymouth and Waybar config. Nothing here is built yet.
